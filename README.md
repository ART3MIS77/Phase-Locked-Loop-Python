# Phase-Locked-Loop-Python
An amateur Python code for a type I Phase Locked Loop with a PI controller.

This was made for a university assignemnt. There was no one who coded a PLL in python so I decided to upload my (somewhat imperfect) code. I know a phase frequency detector is better than a XOR gate for phase detection, but I unfortunately don't have the skills for it lol.
